# Constraint review set

Open `review.html` to inspect each original image, measured references, evidence and editable proposal. Enter your name, revise the JSON, select reviewed tracks and confirm review before exporting. Export does not modify repository drafts. Save reviewed JSON files in a separate directory, then run `vlm-tamp validate-annotations --annotations PATH` before evaluating with them.

All saved annotations are drafts with disabled coverage. Proposed constraints are unverified; published final goals and simulator kinematics do not prove required manipulation stages or contact strategies. The exact verified axes remain separate evidence.

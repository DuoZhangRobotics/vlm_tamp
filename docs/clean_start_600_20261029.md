### What the outcomes establish

- Closing 49 without memory never reduced the opening below its initial 107.26
  degrees and ended 118.26 degrees open. It executed an arc before acquiring a
  grasp, then tried pushes. With memory, successive contacts reduced the opening
  and reached native closure at 545. The winning call completed during its
  approach, with a 12.98 cm/s measured contact-landmark peak; it does not qualify
  a controlled push stroke or retained closure after withdrawal.
- Opening 13 with memory used the recommended jaw-axis sequence but lost its
  grasp. The pad gap fell from 21.96 to 0.14 mm. It reached at most 23.85 degrees
  open and ended closed. The actor read the memory; missing memory delivery is
  not the explanation.
- Its initial front-view hinge estimate had a 37.86 mm axis offset in offline
  grading. Successful practice used another view, began at 27.09 mm offset, and
  later installed a motion-supported revision. No revision was installed in the
  failed fresh run. One checking interval measured only 1.27 degrees, below the
  1.5-degree observability requirement. Grounding and grasp choices both differed,
  so this comparison does not isolate hinge error as the sole cause of slip.
- Opening 13 without memory used pushes rather than a grasp sequence, reached
  51.85 degrees, then lost its progress during later approaches and insertion.
  It also ended closed.
- Opening 37 succeeded under both conditions through grasped manipulation. The
  no-memory actor recovered from selecting the wrong executor for an approach
  plan. The memory actor used an approach, closure and arc with the correct
  gripper commands and finished in fewer controls.

The remaining failure is not explained by a large memory file. Contact retention
and grounding/calibration reliability remain unresolved. A useful subsequent
diagnostic would isolate calibration observability: intermediate sequence
segments currently omit endpoint holds, and a fixed small commanded probe can
produce too little observed rotation for verification. Adaptive probing or
settling needs a separate matched physical test before claiming a remedy.

## Protocol

- One persistent learner practices six episodes, cycling closing states 17/49
  and opening state 13 twice. Each episode has 600 controls and the existing
  30-minute wall limit.
- The learner can keep detailed notebooks and its own context across practice.
  It consolidates transferable lessons into one guidelines file. No old memory
  is injected into this practice block.
- Freeze the resulting learner-authored file and inspect its transfer scope
  before evaluation. Preserve the original text and all failures.
- Fresh evaluations compare no inherited memory with the frozen new memory on
  matched cases and limits. The declared cases live in the study plan. Alternate
  condition order between cases and keep source and memory hashes fixed.
- Evaluation agents may write their own lessons. Those are archived and never
  supplied to the following evaluations in this comparison. A later continued
  learning study can consolidate them separately.

The study is a small comparison, not a statistical success-rate estimate. Cases
excluded from this practice are not claimed globally unseen. No successful
coordinates, state-specific strategy or native object geometry is supplied.

## Memory size

The previous guidelines occupy 6,102 bytes and 790 whitespace-separated words;
the compact tool index occupies 10,337 bytes and 1,365 words. That memory file is
small relative to the conversation history. In the previous six-attempt practice
session, Codex recorded a 258,400-token effective context window, a peak of
244,762 input tokens and three compactions. These are observed client counters,
not the model's maximum API context specification.

The new experiment keeps detailed notebooks on disk and transfers one consolidated
guidelines file. It does not concatenate all previous agent notebooks. The
experiment page records these measurements in `context-size-audit.json`.

The completed clean practice peaked at **199,271 input tokens** and recorded
**zero compactions**. Fresh evaluation peaks ranged from **53,558 to 129,107**,
also with zero compactions, against the same recorded 258,400-token effective
window. These histories include interaction context, not merely the 536-word
memory. There is room for additional concise lessons; the current experiment
does not justify loading all archived histories indiscriminately.

All six evaluators wrote their own findings and guidelines: **12 files** are
retained in their archived workspaces. None were fed into subsequent evaluation
inputs. A future continued-learning block can consolidate selected lessons
without changing the interpretation of this fixed-memory comparison.
